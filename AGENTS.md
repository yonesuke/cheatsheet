# Agent Workflow Guidelines

## About This Repository

This repository contains a collection of technical cheatsheets covering topics like machine learning, numerical computing, and software engineering. **All content in this repository is generated by AI (specifically, Google's specific models).** The goal is to provide quick, accessible reference material for developers and researchers.

## Adding a New Cheatsheet

When you create a new `cheatsheet_*.md` file, you **MUST** follow these steps to ensure the repository remains consistent:

### Workflow: Finalization

When a new cheatsheet is created, **DO NOT** immediately update the README or push.
Instead, wait until the user is satisfied with the cheatsheet content and the conversation has "converged".

**The user triggers the finalization process by saying "finalize" or something equivalent.**

**Upon receiving the "finalize" command, proceed with the following steps:**

1.  **Update `README.md`**:
    *   Add the new cheatsheet filename, topic, and a brief summary to the `Overview` table in `README.md`.
    *   Maintain the alphabetical order of the table.

2.  **Regenerate `cheatsheet_all.md`**:
    *   Use the following command to concatenate files while **excluding** `cheatsheet_all.md` itself:

    ```bash
    rm cheatsheet_all.md 2>/dev/null
    for f in cheatsheet_*.md; do 
      if [[ "$f" != "cheatsheet_all.md" ]]; then 
        cat "$f" >> cheatsheet_all.md
        echo -e "\n\n---\n\n" >> cheatsheet_all.md
      fi
    done
    ```

3.  **Push Changes**:
    *   Commit all changes and push.

    ```bash
    git add .
    git commit -m "Add [Cheatsheet Name] and update documentation"
    git push
    ```
